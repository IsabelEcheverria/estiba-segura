# Estiba Segura · PWA móvil

Aplicación móvil para apoyo al cálculo preliminar de estiba y sujeción de cargas por amarre superior por fricción.

## Incluye
- Cálculo por dirección: adelante, atrás y lateral.
- Semáforo HSE: APTO*, INSUFICIENTE o NO APTO.
- Guardado local en el dispositivo.
- Impresión / Guardar como PDF desde el navegador.
- PWA instalable y funcionamiento offline.
- Sin base de datos ni envío de datos de la verificación a internet.

## Nota HSE
La herramienta está limitada a una estimación preliminar para amarre superior por fricción. No sustituye el procedimiento aprobado, la normativa aplicable, la capacidad de los puntos de anclaje, las instrucciones del fabricante ni una verificación específica de vuelco o amarre directo/diagonal.
